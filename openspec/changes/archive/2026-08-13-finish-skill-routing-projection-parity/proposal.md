## Why

Completing that contract now prevents version guidance, aliases, and Claude/Codex projections from drifting while preserving every existing invocation ID.

## What Changes

- Complete the inventory-owned Laravel 5.4–11/Mix and PHPUnit 9–11 routers with conditional reference resolution and stable compatibility aliases.
- Keep version mechanics, migration traps, and examples behind selected conditional references; keep initial descriptions concise and budget-safe.
- Generate Claude and Codex routing metadata from one normalized manifest and add deterministic parity/repeat-generation checks.
- Preserve distinct React, Next, audit, judge, stocktake, GitNexus, investigation, and review identities; add regression evidence without consolidating them.
- Add explicit static/runtime evidence states and record unavailable consumer probes without overstating support.
- Synchronize the completed discovery capability into main OpenSpec specs and leave the stale ignored partial task file as non-authoritative residue.
