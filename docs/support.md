# DHPK support

The current support route is the public
[DHPK GitHub Issues page](https://github.com/hmj1026/dhpk/issues). This is the
candidate support URL for the OpenAI listing; the plugin is not yet published
in the public Plugins Directory.

## Report an issue

Include only information needed to reproduce the problem:

- DHPK version and whether you used a published plugin, a local development
  marketplace, or another documented compatibility route.
- Host and client version, the affected skill name, and a short reproduction
  sequence.
- Expected and observed behavior, plus relevant sanitized error text.
- For package or listing problems, the artifact SHA-256 digest and the
  `generate`, `validate`, or `verify` verdict. The digest does not reveal the
  artifact contents.

Use a minimal synthetic example when project files are private. Remove API
keys, passwords, OAuth tokens, cookies, personal data, customer information,
proprietary code, private absolute paths, and unredacted transcripts or logs.
Public issues can be read by others and are handled under
[GitHub's privacy policy](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

The support route does not promise a reply, response time, or support SLA.
For information handled by the host or a provider, use that product's support
and privacy controls; see the [privacy policy](./privacy.md).
