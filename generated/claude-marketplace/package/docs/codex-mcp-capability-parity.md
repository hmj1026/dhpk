# Codex MCP capability-parity matrix

This matrix is the migration record for the eight targets named by
`codex-mcp-capability-migration`. The archived predecessor recorded nine
canonical MCP-backed skills and the eight-name command family; its transport
inventory and explicit-only disposition are preserved here as historical
baseline evidence (`docs/skill-platform-migration.md:93-118`,
`openspec/specs/skill-invocation-policy/spec.md:117-134`).

The retirement scope is all nine legacy MCP-backed skill identities:
`codex-architect`, `codex-implement`, `codex-code-review`, `doc-review`,
`test-review`, `codebase-exploration`, `feature-verify`, `issue-analyze`, and
`feasibility-study`. The last two share one row below, so the matrix has eight
rows. No compatibility alias or hidden MCP fallback is retained. The active
owners and explicit optional transports are recorded in the cells below.

Every row has cited migration evidence and an explicit version-pin rollback.
Rollback means pinning the last compatible MCP-backed release; it never means
adding a hidden MCP invocation to the retiring release
(`docs/skill-platform-migration.md:86-89,113-118`).

## Review-owner decision

`dhpk-change-review` and `dhpk-pr-review` remain separate. `codex-code-review`
migrates into `dhpk-change-review`, because its fixed-point, dual-axis, severity,
freshness, degraded-review, and fail-closed gate match that skill's independent
diff/branch review contract and retained `scripts/review.sh --backend cli` path.
`dhpk-pr-review` remains the author-side PR risk, correctness/security/
performance, and squash-merge hygiene workflow. This separation prevents PR
hygiene from being mistaken for an independent change-review verdict
(`skills/dhpk-change-review/SKILL.md:12-32,66-101`,
`skills/dhpk-pr-review/SKILL.md:11-21,23-56,81-114`,
`docs/skill-platform-migration.md:101-111`).
