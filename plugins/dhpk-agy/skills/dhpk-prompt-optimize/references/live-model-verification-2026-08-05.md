# Live model verification snapshot (2026-08-05)

This dated note is a process checkpoint, not a catalog of model IDs. Model
names, effort controls, context limits, and pricing must be looked up at run
time.

Required order for every model-specific recommendation:

1. Query Context7 for the current provider/API documentation.
2. Confirm the same parameter or capability in the provider's official
   documentation.
3. Record the lookup date and direct source links in the output.
4. If either lookup is unavailable or conflicts, mark the recommendation
   `unverified`, remove model-specific claims, and ask the user for the exact
   target before proceeding.

Never fill a missing value with a remembered model name, token limit, default,
or pricing claim. Refresh this note's date when its verification process or
source policy changes.
